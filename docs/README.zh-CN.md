# 文档中心

[English](README.md) | 简体中文 | [项目首页](../README.zh-CN.md)

ChatGPT Tunnel Console 通过 OpenAI Tunnel，让 ChatGPT 或 Codex 连接 SSH 主机、传输文件并操作 Linux 桌面。按下列入口完成部署，或使用已有连接。

## 开始使用

- [安装与升级](installation.zh-CN.md) — 准备隧道、使用 Docker 或原生服务部署、连接 ChatGPT、备份和升级。
- [命令、会话与文件](usage.zh-CN.md) — 选择主机、运行命令、保留交互终端和传输文件。
- [故障排查](troubleshooting.zh-CN.md) — 排查启动、连接、工具发现、传输和桌面问题。

## 文件与桌面

- [ChatGPT 附件直传](attachments.zh-CN.md) — 将聊天附件直接上传到 SSH 主机。
- [原生 Linux 桌面](desktop.zh-CN.md) — 启动 X11 桌面、截图并操作鼠标和键盘。
- [VNC 桌面](vnc.zh-CN.md) — 为自带桌面添加 VNC，或连接兼容的已有服务。
